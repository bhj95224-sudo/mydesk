# 확정이 필요한 항목

초기 구현을 막지 않는 항목은 임시값으로 넣었습니다. 최종 디자인과 사례 페이지를 완성하기 전에 아래 내용을 결정하면 됩니다.

## 우선 확인

1. **메인 책상 최종 비주얼** — 현재는 사용자가 제공한 `임시.png`를 그대로 사용합니다. 최종 이미지나 Figma 화면이 정해지면 교체하고 모니터 클릭 위치를 다시 맞춥니다.
2. **프로젝트별 대표 이미지/로고/폰트** — 현재 네 대표 화면은 CSS 임시 이미지입니다. 실제 원본을 `public/assets/`에 넣고 연결해야 합니다.
3. **프로젝트별 소개 정보** — 설화수와 hourtention의 한 줄 소개, 작업 유형, 연도, 사용 도구. 비플레인 문구도 최종 확인이 필요합니다.
4. **자두야 개인 기여 범위** — 기존 자두야 문서는 팀 프로젝트 전체 서비스 문서이므로, 이 포트폴리오에서 본인이 맡은 화면·디자인·코드·결과를 분명히 구분해야 합니다.

## 다음 단계에서 결정

6. **프로젝트 표시 순서와 첫 화면** — 현재는 비플레인 → 설화수 → hourtention → 자두야, 첫 화면은 비플레인입니다.
7. **자동 전환 시간** — 임시 6.5초. 최종 콘텐츠를 읽기에 충분한지 확인합니다.
8. **자세히 보기 동선** — 새 내부 사례 페이지, 외부 사이트, PDF 중 무엇으로 연결할지와 URL.
9. **메인 책상의 다른 물건의 역할** — 키보드를 도구/역량 화면으로 연결할지, 소개·연락처를 어디에 둘지.
10. **배포 방식과 도메인** — GitHub Pages, Vercel 등 실제 공개 위치와 주소.

## 이미 정해진 조건

- 개인 작업이며 팀 협업용 문서와 승인 절차는 필요하지 않습니다.
- React 기반 웹사이트입니다.
- 1920 × 1080 데스크톱 기준, 좌우 30px 여백, 1860px 콘텐츠 폭입니다.
- 사용자가 보여준 겹친 프로젝트 창은 메인페이지가 아니라 **모니터 클릭 후 화면**입니다.
- 포트폴리오 저장소: `https://github.com/bhj95224-sudo/mydesk.git`.
- 배경 격자는 사용자가 제공한 21px `linear-gradient` CSS를 사용합니다.
- 메인 책상은 사용자가 제공한 투명 배경 PNG를 임시 이미지로 사용합니다.
